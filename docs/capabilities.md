# Capability status and explicit omissions

This release combines the full eligible internal source collection and AI Factory plan with the separately maintained portable core. Recorded portability transformations and explicit license exclusions mean it is not a blind export of a live personal environment. No old project's PASS or registration evidence is transferred to a new machine.

| Capability | Implemented / included | Evidence boundary |
|---|---|---|
| Proportional lifecycle and ADR/UI/ship criteria | Full generic documented stages, one primary record | Instructions are not proof of model behavior |
| Planning skills | Four curated personal skills with core-doc references | Static validation; independent behavioral review pending |
| Inventory and role/binding checks | Read-only helper, host/session catalog/entitlement/budget declarations | Validates declarations, never binds a model or proves access |
| Independent review package | Git scoped source/index/base snapshots, content hashes, response/freshness/delta checks | Structural integrity is not proof of reviewer independence or correctness |
| Session guard | Explicit private store, thresholds, checkpoint/resume and synthetic hook adapter | No live registrations or CLI acceptance; metadata snapshot is not content hash |
| CRG freshness | Generic source/hash/coverage/untracked and bounded recovery contract | External binary/server not installed or required |
| Graphify | Optional local-only adapter for tested 0.9.92 mode | No binary, no universal accuracy claim; incremental/source-resolution misses documented |
| Staged install/update/rollback | Offline managed root, opt-in components, receipts/backups, guarded writes | Requires exclusive writer window; author fixtures, independent review pending |
| New/existing project routes | Concrete preflight and adapter acceptance instructions | No automatic product entry edits or architecture migration |
| New PC | Staged package plus manual host/dependency inventory | No automatic auth, tool install, model router, hook activation or global skill linking |

The [full collection](../collection/README.md) includes the original internal spec-flow/grilling/TDD/code-review/ship-report/UI/entity/CRG families, full plan/rules/helpers and supporting files. It accounts for 84 physical shared definitions; 11 have explicit license restrictions and are inventory-only. External symlink targets, `b2b*`, project-local and host/system/plugin collections are excluded. No secret-bearing host configuration, raw vault/session content or product graphs are included. Windows is unsupported; POSIX/macOS is the tested platform family. Native discovery and independent acceptance remain pending.

Reviewer routing: honor the user's chosen independent existing session. Never spawn or message another reviewer implicitly. The shared toolkit reviewer can remain unassigned while author implementation/tests proceed. Project-specific review packages belong to a later approved project diff and exact snapshot; no invented empty rollout packages constitute acceptance.
