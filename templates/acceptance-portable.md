
# AI Factory integration acceptance

[Entry](../docs/portable/onboarding.md) · [Change protocol](../docs/portable/change-protocol.md)

Insert into the existing task record; do not create a duplicate report for the sake of the template. Fill all fields with facts or UNKNOWN/BLOCKED/N/A with a reason.

- Root / branch / HEAD / relevant dirty scope / date:
- Authorization and exact files; preserved stack/workflow/contracts; owner:
- Startup routing: purpose → new subagent / named existing session / unresolved; owner/reference, current selection evidence, delivery owner, resource coordination; no duplicate spawn/message.
- Review package ID: task/author/reviewer IDs, pinned scope/diff/acceptance/contracts, raw checks/exits/results; response status; final-delta scope and accepted unchanged evidence. Missing response/evidence → NOT_TESTED/BLOCKED. See [contract](../docs/portable/review-handoff.md).
- Manifest/preflight evidence; manual review of semantic conflicts and side effects:
- Canonical adapter/entry; baseline/applied hashes, backup/receipt, diff:
- Obsidian: vault/Shared paths → resolved canonical target; note/report path; verified currency/source/date; current authorization scope; SYNCED/NOOP/PENDING/BLOCKED/N/A + evidence or reason/fallback/next action. Record the Shared target once; visibility is neither runtime evidence nor future authorization.
- Repeat: NOOP or conflict BLOCKED; restore rehearsal evidence (fixture only), actual restore if instructed:

For checks: PASS/FAIL/BLOCKED/N/A with a reason. Forward-test with fresh context: new minimal, existing own workflow, partial, missing skill/CRG, stale CRG, unavailable model, hosts differ, normative conflict, repeated onboarding. Preserve the raw prompt/result; do not give the reviewer the expected verdict in advance.

Unresolved owner decisions: conflict sources → impact → dependent BLOCKED portion → owner/one next action. Other authorized portions may be configured; do not call the entire integration fully complete if a required gate remains BLOCKED. If no required decisions remain unresolved — documentary acceptance; runtime status is separate.

Summary: actual changed files, checks performed, independent review, what was not run, remaining decisions, a short startup prompt. There is no guarantee that an arbitrary repository will not need human policy decisions.
